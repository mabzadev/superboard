# Étiquettes de triage

Les compétences d’ingénierie utilisent cinq rôles canoniques de triage. Ce fichier associe chaque rôle à l’étiquette GitHub utilisée dans `mabzadev/superboard`.

| Rôle canonique    | Étiquette GitHub  | Signification                                               |
| ----------------- | ----------------- | ----------------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Le responsable doit évaluer le ticket                       |
| `needs-info`      | `needs-info`      | Des informations supplémentaires sont attendues de l’auteur |
| `ready-for-agent` | `ready-for-agent` | Le ticket est entièrement spécifié et prêt pour un agent    |
| `ready-for-human` | `ready-for-human` | Le ticket nécessite une intervention humaine                |
| `wontfix`         | `wontfix`         | Le ticket ne recevra pas de suite                           |

Lorsqu’une compétence mentionne un rôle canonique, appliquez l’étiquette GitHub correspondante dans ce tableau.

Ces chaînes peuvent être modifiées ultérieurement pour correspondre au vocabulaire réel du dépôt, sans changer les rôles canoniques utilisés par les compétences.
