# Étiquettes de triage

Utilisez ces étiquettes dans `mabzadev/superboard`.

| Rôle            | Étiquette       | Signification                          |
| --------------- | --------------- | -------------------------------------- |
| needs-triage    | needs-triage    | Ticket à évaluer                       |
| needs-info      | needs-info      | Informations supplémentaires attendues |
| ready-for-agent | ready-for-agent | Ticket spécifié et prêt pour un agent  |
| ready-for-human | ready-for-human | Intervention humaine nécessaire        |
| wontfix         | wontfix         | Ticket sans suite                      |

Lorsqu’un skill nomme un rôle, appliquez l’étiquette correspondante.
Modifiez ce mapping si les conventions du dépôt changent.
